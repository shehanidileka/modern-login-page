# Modern Login Page 🚀

A modern, responsive, and visually appealing login page built using **HTML5**, **CSS3**, and **JavaScript**. It features a stunning glassmorphism design with animated background elements and client-side password validation.

## ✨ Features

* **Glassmorphism Design:** Modern translucent UI with background blur effects.
* **Animated Background:** Smoothly floating and scaling glowing background circles.
* **Client-Side Validation:** Ensures the password is at least 6 characters long before submission using JavaScript.
* **Interactive Elements:** Smooth input focus effects, custom checkboxes, and hover animations.
* **Google Sign-In Option:** Integrated styled button for social login.
* **Fully Responsive:** Optimized seamlessly for both desktop and mobile devices.

## 🛠️ Technologies Used

* **HTML5** 
* **CSS3** 
* **JavaScript**
